# Group Work Market (Socio+)

A community-first society commerce and group work marketplace. Repair appliances together, unlock bulk grocery savings, buy & sell second-hand within your society, and book verified local service providers.

## Key Features

- 🛠️ **Group Repairs & Services**: Pool requests with neighbors to unlock tiered group discounts on appliance repairs and home services.
- 🛒 **Bulk Buying & Savings**: Team up on groceries and household essentials to achieve wholesale group pricing.
- 🔄 **Society Marketplace**: Buy and sell pre-loved goods safely and securely within verified gated communities.
- ⭐ **Verified Local Service Providers**: Discover vetted electricians, plumbers, and technicians with resident reviews.

## Tech Stack

- **Framework**: React 19 + TypeScript
- **Bundler**: Vite
- **Styling**: Tailwind CSS v4
- **Icons**: Lucide React
- **Effects**: Canvas Confetti

## Getting Started

### Prerequisites

- Node.js (v18 or higher recommended)
- npm

### Installation

```bash
npm install
```

### Development Server

Start the local Vite development server:

```bash
npm run dev
```

### Production Build

Compile TypeScript and bundle for production:

```bash
npm run build
```
